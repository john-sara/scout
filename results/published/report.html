What the error analysis fixed

The first run exposed three problems: long pages cut off at 6,000 characters, runs that spent every step searching without answering, and a judge that could not see the docs. The first run was re-graded once the judge could see the docs, so this compares answers and not judge versions. After the second run, the judge was also shown the pages each answer cited, which removed false penalties for correct claims on other real pages. Part of the last gain comes from that grading fix, not from the agent.
